## Testing the Backend

### Option 1: Using Swagger UI (Recommended)

1. **Start the portal:**
   ```bash
   cd portal
   docker-compose -f docker-compose.full.yml up -d
   docker-compose -f docker-compose.full.yml exec backend python -m app.db.init_db
   ```

2. **Access Swagger UI:**
   Open http://localhost:8000/docs

3. **Authenticate:**
   - Click "Authorize" button
   - Login via `/api/v1/auth/login` with:
     ```json
     {
       "email": "user@example.com",
       "password": "user123"
     }
     ```
   - Copy the `access_token` from response
   - Click "Authorize" and paste token as: `Bearer <token>`

4. **Test Visual Designer endpoints:**
   - **GET /api/v1/designer/components** - See available Azure components
   - **POST /api/v1/designer/projects** - Create a visual design project
   - **POST /api/v1/designer/projects/{id}/generate/terraform** - Generate Terraform!

### Option 2: Using cURL

```bash
# 1. Login and get token
TOKEN=$(curl -X POST http://localhost:8000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"user@example.com","password":"user123"}' \
  | jq -r '.access_token')

# 2. List available components
curl http://localhost:8000/api/v1/designer/components \
  -H "Authorization: Bearer $TOKEN" | jq

# 3. Create a visual design project
PROJECT_ID=$(curl -X POST http://localhost:8000/api/v1/designer/projects \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "my-first-design",
    "description": "Testing visual designer",
    "environment": "development",
    "diagram": {
      "nodes": [
        {
          "id": "vnet-1",
          "type": "azure-vnet",
          "position": {"x": 100, "y": 100},
          "data": {
            "name": "vnet-hub",
            "address_space": ["10.0.0.0/16"],
            "location": "eastus"
          }
        },
        {
          "id": "subnet-1",
          "type": "azure-subnet",
          "position": {"x": 150, "y": 200},
          "data": {
            "name": "subnet-web",
            "address_prefixes": ["10.0.1.0/24"]
          }
        }
      ],
      "edges": [
        {
          "id": "e1",
          "source": "vnet-1",
          "target": "subnet-1",
          "type": "contains"
        }
      ]
    }
  }' | jq -r '.id')

# 4. Generate Terraform code!
curl -X POST "http://localhost:8000/api/v1/designer/projects/$PROJECT_ID/generate/terraform" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"validate": true, "format": true}' | jq '.files'
```

## Example: Generate Terraform from Visual Diagram

**Input (Visual Diagram JSON):**
```json
{
  "nodes": [
    {
      "id": "hub-vnet",
      "type": "azure-vnet",
      "position": {"x": 100, "y": 100},
      "data": {
        "name": "vnet-hub-prod",
        "address_space": ["10.0.0.0/16"],
        "location": "eastus"
      }
    },
    {
      "id": "gateway-subnet",
      "type": "azure-subnet",
      "position": {"x": 150, "y": 200},
      "data": {
        "name": "GatewaySubnet",
        "address_prefixes": ["10.0.0.0/24"]
      }
    }
  ],
  "edges": [
    {
      "id": "contains-1",
      "source": "hub-vnet",
      "target": "gateway-subnet",
      "type": "contains"
    }
  ]
}
```

**Output (Generated Terraform):**
```hcl
# Generated by Visual IaC Designer
# Project: my-infrastructure
# Generated: 2025-11-19T...

# Resource Group
resource "azurerm_resource_group" "main" {
  name     = var.resource_group_name
  location = var.location
  tags     = var.tags
}

# vnet-hub-prod
module "hub_vnet" {
  source = "../../modules/networking/azure-vnet"

  resource_group_name = azurerm_resource_group.main.name
  location            = var.location
  name                = "vnet-hub-prod"
  address_space       = ["10.0.0.0/16"]
}

# GatewaySubnet
module "gateway_subnet" {
  source = "../../modules/networking/azure-subnet"

  resource_group_name = azurerm_resource_group.main.name
  location            = var.location
  name                = "GatewaySubnet"
  address_prefixes    = ["10.0.0.0/24"]

  depends_on = [module.hub_vnet]
}
```

## API Endpoints Reference

### Projects
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/v1/designer/projects` | List all projects |
| POST | `/api/v1/designer/projects` | Create new project |
| GET | `/api/v1/designer/projects/{id}` | Get project details |
| PATCH | `/api/v1/designer/projects/{id}` | Update diagram/config |
| DELETE | `/api/v1/designer/projects/{id}` | Delete project |

### Code Generation
| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/v1/designer/projects/{id}/generate/terraform` | Generate Terraform code |
| POST | `/api/v1/designer/projects/{id}/validate` | Validate configuration |

### Components
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/v1/designer/components` | List available components |
| GET | `/api/v1/designer/components/{type}` | Get component schema |

## Available Azure Components

| Type | Name | Category | Module |
|------|------|----------|--------|
| `azure-vnet` | Virtual Network | networking | azure-vnet |
| `azure-subnet` | Subnet | networking | azure-subnet |
| `azure-nsg` | Network Security Group | networking | azure-nsg |
| `azure-vm` | Virtual Machine | compute | azure-vm |
| `azure-storage` | Storage Account | storage | azure-storage-account |

Each component includes:
- **Schema**: Input/output definitions
- **Default Config**: Pre-filled values
- **UI Config**: Size, color, icon
- **Terraform Module**: Path to module

## Troubleshooting

**"Module not found" error:**
```bash
docker-compose -f docker-compose.full.yml restart backend
docker-compose -f docker-compose.full.yml logs backend
```

**Can't access Swagger UI:**
- Ensure backend is running on port 8000
- Check `docker-compose -f docker-compose.full.yml ps`

**Validation errors:**
- Check diagram has valid node IDs
- Ensure edges reference existing nodes
- No circular dependencies
